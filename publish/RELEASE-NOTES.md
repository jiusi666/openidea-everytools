# EveryTools 0.1.1

中文开发者的 16 个效率工具合集。这一版只改介绍与市场的推荐位，功能与能力不变。

- 插件介绍补上参与开发引导与 Java 技术交流 Q 群 700072697。
- registry 条目新增 `suggest`，含 `pom.xml` / `package.json` 等构建文件的项目会在市场看到「Suggested for This Project」。
- README 补上架状态、市场安装方式、路线图与群联系方式。
- 能力仍是 `editor.read` / `editor.write` / `clipboard` / `storage`。

Release 附件：`jiusi.everytools-0.1.1.oiplugin`，源码 Apache-2.0。
